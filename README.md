# Sistema de gestión de gimnasio

Proyecto de equipo para desarrollar una API REST y una base de datos que permitan gestionar las operaciones básicas de un gimnasio.

> **Estado del proyecto:** propuesta inicial pendiente de revisión y aprobación del equipo.

## Objetivo

Construir progresivamente un sistema para gestionar los datos del gimnasio, sus socios, los planes de membresía y los pagos. En fases posteriores se podrán incorporar el control de acceso, las clases, las reservas y la gestión de varias sedes.

## Alcance por fases

1. **Configuración y gestión básica:** datos del gimnasio, planes y socios.
2. **Contratación y pagos:** asignación de planes, pagos y consulta de membresías.
3. **Control de acceso:** tarjetas o pulseras, validación de membresías y registro de entradas.
4. **Funcionalidades complementarias:** entrenadores, clases y reservas.
5. **Expansión a varias sedes:** posible ampliación futura.

## Tecnologías

Las tecnologías definitivas están pendientes de acuerdo del equipo. Python, MySQL, Docker y un framework para la API son opciones que se están valorando. Git y GitHub se utilizarán para el control de versiones y la colaboración.

## Estado

La documentación recoge una propuesta de partida. Las decisiones funcionales y técnicas deben revisarse en equipo antes de comenzar la implementación.
